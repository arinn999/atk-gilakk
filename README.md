# 🖊️ PenaKita - Website Toko Alat Tulis Online

Aplikasi web e-commerce sederhana untuk penjualan alat tulis kantor dan sekolah yang dibangun menggunakan **HTML5**, **CSS3**, dan **Vanilla JavaScript**.

## ✨ Fitur Utama
- **Katalog Produk & Harga:** Menampilkan daftar produk alat tulis lengkap dengan harga dalam format Rupiah (`IDR`).
- **Keranjang Belanja (Cart):** Menambah item, mengubah kuantitas (`+`/`-`), menghitung total harga otomatis, dan menyimpan data keranjang menggunakan `localStorage`.
- **Sistem Autentikasi Sederhana (Login/Logout):** Pengguna dapat masuk menggunakan username untuk melakukan transaksi.
- **Proses Pembelian (Checkout):** Validasi status login dan ringkasan pembayaran sebelum pesanan diproses.
- **Desain Responsif:** Tampilan menyesuaikan layar desktop maupun perangkat mobile.
